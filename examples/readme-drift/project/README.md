# Synthetic greeting project

This intentionally small fixture has no dependencies or network access in its commands.

## Linux quickstart

```bash qsg=greeting-linux
node ./scripts/hello.mjs
```

## Windows quickstart

```powershell qsg=greeting-windows
node ./scripts/hello.mjs
```

The separate smoke test runs a fixed command, not the command text in this README.
The contrast runner changes only the selected README command in a temporary copy.
